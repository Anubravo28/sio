Operational Deployment Guide

Deploying Sio Dhago on Vercel with Firebase

Complete step-by-step instructions for database rules, hosting setup, and environment management.

Step A: Realtime Database Security Rules

Go to Firebase Console → Realtime Database → Rules tab. Paste the following configuration:

{
  "rules": {
    "orders": {
      ".read": true,
      ".write": true,
      ".indexOn": ["status", "timestamp"]
    }
  }
}

Step B: Cloud Firestore Security Rules (Alternative)

If using Firestore collection instead of Realtime DB, configure under Firestore → Rules:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if true;
    }
  }
}

Option 1: Deploy via Vercel GitHub Integration (Recommended)

  1. Push your website code (index.html and admin.html) to a GitHub repository.
  2. Log in to Vercel.com and click "Add New..." → "Project".
  3. Select your GitHub repo and click "Import".
  4. Under Framework Preset, select "Other" or leave as static HTML.
  5. Click Deploy. Vercel will instantly generate a global SSL URL.

Option 2: Deploy via Vercel CLI

# Install Vercel CLI globally
npm i -g vercel

# Login and deploy
vercel login
vercel --prod

Recommended vercel.json File

Place this file in your root folder for clean route redirects and glassmorphism header caching:

{
  "rewrites": [
    { "source": "/admin", "destination": "/admin.html" },
    { "source": "/shop", "destination": "/index.html" }
  ],
  "headers": [
    {
      "source": "/(.*)",
      "headers": [
        { "key": "X-Content-Type-Options", "value": "nosniff" },
        { "key": "X-Frame-Options", "value": "DENY" }
      ]
    }
  ]
}
